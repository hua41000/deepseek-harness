会话花费估算插件

在会话视图新增一个“花费”页签：浏览器端从已加载的会话事件中为每一步找出模型与时段，按单价换算成人民币，汇总出每轮花费、会话合计和缓存节省。

payments背景与设计原则

DSH 现有界面只显示 token 数。DeepSeek 按模型、缓存是否命中、输入或输出、高峰或空闲时段分别计价，用户无法从 token 数心算出花费。

  • 零宿主改动：不新增会话事件、投影或服务。模型 ID 从已有的 request/header 推出，时间取自 step/start。
  • 独立实验包：@deepseek-ai/dsh-experimental-client-ui-cost，页签注册、Definition 与 view target 的写法沿用 client-ui-stats；分页不照搬它，直接调用会话的 loadOlder()。只通过 --patch overlay 挂载。
  • 规则集中在纯函数：时段、取价、计价、汇总、金额格式都在 cost-pricing.ts 和 cost-format.ts 中，与界面分离，便于逐条单测。
  • 配置错误加载即失败：单价配置由 schemastery 校验，负数、非数字或缺少字段都会让插件启动失败并报出字段路径，不会降级成未定价。
  • 宁缺不错：推不出模型或没有单价的步骤不计入金额，在合计卡注明“不含 N 步未定价”。

account_tree整体架构

route数据流程

  • 没有用量记录的步骤（取消、失败、进行中）不产生节点，既不计价，也不算作未定价。
  • step/start 不在窗口内时，开始时间回退为 assistant/message 的时间。只有窗口第一步可能受影响。
  • 配置无效时宿主加载失败；页面拿不到全局配置时，浏览器端也直接报错，不回退到内置价，页签不会出现。
  • “加载更早”按钮直接调用 session.loadOlder()，加载中和是否还有更早轮次分别读取会话快照的 loadingOlder 和 hasMore。

rule模型归属与取价

  • 高峰：北京时间周一至周五 [09:00, 12:00) 与 [14:00, 18:00)，其余为空闲。按 UTC+8 偏移计算，与浏览器时区无关；不识别节假日。
  • 配置按模型整条提供（两个时段 × 三个单价），整条替换内置价；缓存写入 token 按未命中单价计价。

拟议代码cost-builder.ts · attributeModels

export function attributeModels(nodes: Iterable<CostViewNode>): CostSnapshot {
  const routes: { seq: number; model: string }[] = []
  const steps: CostStep[] = []
  for (const node of nodes) {
    switch (node.data.kind) {
      case 'route': routes.push(node.data); break
      case 'step': steps.push(node.data.step); break
      default: assertNever(node.data)
    }
  }
  routes.sort((a, b) => a.seq - b.seq)
  steps.sort((a, b) => a.messageSeq - b.messageSeq)
  let cursor = -1
  const attributed = steps.map((step) => {
    // 请求头在同一步内先于 assistant/message 写入，用严格小于
    while (cursor + 1 < routes.length && routes[cursor + 1]!.seq < step.messageSeq) cursor++
    return { ...step, model: cursor >= 0 ? routes[cursor]!.model : null }
  })
  return { steps: attributed, windowHasHeader: routes.length > 0 }
}

拟议代码cost-pricing.ts · 时段与单步计价

const BEIJING_OFFSET_MS = 8 * 3_600_000

export function pricePeriod(epochMs: number): PricePeriod {
  const beijing = new Date(epochMs + BEIJING_OFFSET_MS)
  const day = beijing.getUTCDay()                 // 0 = 周日
  if (day === 0 || day === 6) return 'offPeak'
  const minute = beijing.getUTCHours() * 60 + beijing.getUTCMinutes()
  const peak = (minute >= 540 && minute < 720) || (minute >= 840 && minute < 1080)
  return peak ? 'peak' : 'offPeak'
}

export function priceStep(step: CostStep, model: string | null, table: PriceTable) {
  // hasOwn：防止 'toString' 等原型链上的键被当成模型
  if (model === null || !Object.hasOwn(table, model)) return null
  const unit = table[model]![pricePeriod(step.startTime)]
  const cost = (step.miss * unit.cacheMiss + step.hit * unit.cacheHit
    + step.write * unit.cacheMiss + step.output * unit.output) / 1_000_000
  const savings = step.hit * (unit.cacheMiss - unit.cacheHit) / 1_000_000
  return { cost, savings }
}

拟议代码cost-pricing.ts · 汇总

export function priceSummary(snapshot: CostSnapshot, table: PriceTable, fallbackModel: string | null): CostSummary {
  // 只有窗口内没有任何请求头时，lastUsed 才能代表整个窗口的模型
  const fallback = snapshot.windowHasHeader ? null : fallbackModel
  const turns = new Map<number, { input: number; output: number; cost: number; priced: number; unpriced: number }>()
  const models = new Set<string>()
  let total = 0, savings = 0, pricedSteps = 0, unpricedSteps = 0
  for (const step of snapshot.steps) {
    const model = step.model ?? fallback
    if (model !== null) models.add(model)
    const row = turns.get(step.turn) ?? { input: 0, output: 0, cost: 0, priced: 0, unpriced: 0 }
    row.input += step.miss + step.hit + step.write
    row.output += step.output
    const priced = priceStep(step, model, table)
    if (priced === null) { row.unpriced++; unpricedSteps++ }
    else { row.cost += priced.cost; row.priced++; total += priced.cost; savings += priced.savings; pricedSteps++ }
    turns.set(step.turn, row)
  }
  return {
    total, savings, models: [...models], pricedSteps, unpricedSteps,
    turns: [...turns].sort(([a], [b]) => a - b).map(([turn, r]) => ({
      turn, input: r.input, output: r.output,
      cost: r.priced === 0 ? null : r.cost,          // 整轮未定价
      partial: r.priced > 0 && r.unpriced > 0,       // 部分未定价，金额后加标记
    })),
  }
}

const unit = z.object({
  cacheHit: z.number().min(0).required(),
  cacheMiss: z.number().min(0).required(),
  output: z.number().min(0).required(),

export const Config: z<Partial<Config>, Config> = z.object({
  prices: z.dict(z.object({ peak: unit.required(), offPeak: unit.required() })).default({}),

// 宿主入口：不提供服务，只把校验后的配置写入页面
export function apply(ctx: Context, config: Config): void {
  ctx.on('webserver/index-inject', (table) => {
    table.push({ kind: 'global', name: '__DSH_UI_COST_CONFIG__', value: config })
  })
}

// 浏览器端：跨进程输入，用同一 schema 再校验一次
const injected = (globalThis as { __DSH_UI_COST_CONFIG__?: Partial<Config> }).__DSH_UI_COST_CONFIG__
if (injected === undefined) {
  // 宿主入口成功时总会注入；拿不到说明宿主入口未运行或配置无效，不回退到内置价
  throw new Error('client-ui-cost: price configuration was not injected; the host entry did not run or its config is invalid')
}
const prices = resolvePrices(Config(injected).prices)

拟议代码cost-format.ts · 金额格式

export function formatYuan(value: number): string {
  if (value > 0 && value < 0.00005) return '<¥0.0001'
  // 4 位四舍五入会得到 1.0000 时改用 2 位
  return value >= 0.99995 ? `¥${value.toFixed(2)}` : `¥${value.toFixed(4)}`
}

summarize方案小结

本次新增一个独立的浏览器端实验插件，不改动现有事件、投影和服务：通过“每步取前一条请求头的模型”从已有日志中推出模型，计价规则集中在可单测的纯函数中。主要取舍是接受窗口最前段偶尔推不出模型（计入未定价，加载更早后恢复），以此避免修改核心事件格式和两套 SDK 快照。压缩摘要调用和失败重试消耗的 token 不在本次统计范围内，估算可能偏低。
