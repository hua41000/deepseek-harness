会话花费估算插件

在会话视图新增一个“花费”页签：浏览器端从已加载的会话事件中为每一步找出模型与时段，按单价换算成人民币，汇总出每轮花费、会话合计和缓存节省。

payments背景与设计原则

DSH 现有界面只显示 token 数。DeepSeek 按模型、缓存是否命中、输入或输出、高峰或空闲时段分别计价，用户无法从 token 数心算出花费。

  • 零宿主改动：不新增会话事件、投影或服务。模型 ID 从已有的 request/header 推出，时间取自 step/start。
  • 独立实验包：@deepseek-ai/dsh-client-ui-cost（目录 packages/experimental/client-ui-cost；实验包禁用 dsh-experimental- 前缀，包名登记为例外），页签注册、Definition 与 view target 的写法沿用 client-ui-stats；分页不照搬它，直接调用会话的 loadOlder()，按钮用共享的 Button。只通过 --patch overlay 挂载。
  • 两个编译面：宿主面只含 src/index.ts、src/config.ts 与纯类型的 cost-contract.ts；浏览器面含 src/client 与共享的 config.ts。
  • 规则集中在纯函数：时段、取价、计价、汇总、金额格式都在 cost-pricing.ts 和 cost-format.ts 中，与界面分离，便于逐条单测。
  • 配置错误加载即失败：单价配置由 schemastery 校验，负数、Infinity、NaN、非数字或缺少字段都会让插件启动失败并报出字段路径，不会降级成未定价。schemastery 的范围检查放过 NaN，因此另有一层自定义检查。
  • 宁缺不错：推不出模型或没有单价的步骤不计入金额，在合计卡注明“不含 N 步未定价”。

account_tree整体架构

route数据流程

  • 没有用量记录的步骤（取消、失败、进行中）不产生节点，既不计价，也不算作未定价。
  • cost-step 的状态只保存 step/start 的时间，用量直接取该步最后一条 assistant/message。起点不在窗口内时，开始时间回退为消息时间，只有窗口第一步可能受影响。
  • 会话窗口总是日志的连续后缀（replaceWindow 收完整连续窗口，prepend 只加更早事件），因此窗口内没有请求头时可以用 lastUsed 回退。
  • 回退模型记在插件按会话注入的 windowModel 中（注入结果按会话缓存），切走页签或视图重新挂载都不会丢失；请求头实时进入窗口后，已计价的步骤仍按记录的模型计价，合计不会下降。
  • 断线续传、缺口修复或重新打开会把窗口整体换成更晚的尾页，此时窗口起点后移，旧记录被丢弃并按新窗口重新记录。
  • 配置无效时宿主入口加载失败，但浏览器端代码仍会下发；页面拿不到全局配置时，浏览器端在任何注册之前报错，不回退到内置价，页签不会出现，DSH 其余部分照常运行。
  • “加载更早”按钮直接调用 session.loadOlder()；视图用槽位标准属性 useSession 读取 hasMore、loadingOlder 与 historyLoadStatus。

rule模型归属与取价

  • 保留首个模型：lastUsed 只因新的请求头而改变，窗口仍无请求头时它变化，说明那条请求头还没进入窗口。
  • 已知残余风险（暂不修复）：缺口修复补回的页不带模型投影、模型切换恰好落在缺失段、且 lastUsed 晚于窗口更新时，记录会保留切换前的模型，这些步骤按旧模型计价且不提示。打开会话与断线续传的页会先写入投影，不受影响。
  • 高峰：北京时间周一至周五 [09:00, 12:00) 与 [14:00, 18:00)，其余为空闲。按 UTC+8 偏移计算，与浏览器时区无关；不识别节假日。
  • 配置按模型整条提供（两个时段 × 三个单价），整条替换内置价；缓存写入 token 按未命中单价计价。

现有实现（摘录）cost-builder.ts · attributeModels

export function attributeModels(nodes: Iterable<CostViewNode>): CostSnapshot {
  const routes: { seq: number; model: string; reason: RequestHeaderReason }[] = []
  const steps: CostStep[] = []
  for (const node of nodes) {
    switch (node.data.kind) {
      case 'route': routes.push(node.data); break
      case 'step': steps.push(node.data.step); break
      default: assertNever(node.data)
    }
  }
  routes.sort((a, b) => a.seq - b.seq)
  steps.sort((a, b) => a.messageSeq - b.messageSeq)
  // series 只在与上一条请求头相同时写入，所以第一条为 series 时，它之前的步骤沿用其模型
  const leading = routes[0]
  let model: string | null = leading?.reason === 'series' ? leading.model : null
  let next = 0
  const attributed = steps.map((step): AttributedCostStep => {
    // 请求头在同一步内先于 assistant/message 写入，用严格小于
    for (let route = routes[next]; route !== undefined && route.seq < step.messageSeq; route = routes[++next]) model = route.model
    return { ...step, model }
  })
  return { steps: attributed, windowHasHeader: routes.length > 0 }
}

现有实现（摘录）cost-pricing.ts · 时段与单步计价

const BEIJING_OFFSET_MS = 8 * 3_600_000

export function pricePeriod(epochMs: number): PricePeriod {
  const beijing = new Date(epochMs + BEIJING_OFFSET_MS)
  const day = beijing.getUTCDay()                 // 0 = 周日
  if (day === 0 || day === 6) return 'offPeak'
  const minute = beijing.getUTCHours() * 60 + beijing.getUTCMinutes()
  const peak = (minute >= 540 && minute < 720) || (minute >= 840 && minute < 1080)
  return peak ? 'peak' : 'offPeak'
}

export function priceStep(step: CostStep, model: string | null, table: PriceTable) {
  // hasOwn：防止 'toString' 等原型链上的键被当成模型
  if (model === null || !Object.hasOwn(table, model)) return null
  const unit = table[model]![pricePeriod(step.startTime)]
  const cost = (step.miss * unit.cacheMiss + step.hit * unit.cacheHit
    + step.write * unit.cacheMiss + step.output * unit.output) / 1_000_000
  const savings = step.hit * (unit.cacheMiss - unit.cacheHit) / 1_000_000
  return { cost, savings }
}

现有实现（摘录）cost-pricing.ts · 窗口模型记录

export function rememberWindowModel(previous: WindowFallback | null, snapshot: CostSnapshot, lastUsed: string | null): WindowFallback | null {
  const first = snapshot.steps[0]
  if (first === undefined) return previous
  // 加载更早只让起点前移，实时追加不改变起点；起点后移说明窗口被替换为更晚的页
  const kept = previous !== null && first.messageSeq > previous.fromSeq ? null : previous
  if (snapshot.windowHasHeader) return kept                 // 有请求头：记录冻结
  if (kept === null) return lastUsed === null ? null : { model: lastUsed, fromSeq: first.messageSeq }
  // 保留首个模型，起点随更早的页前移
  return first.messageSeq < kept.fromSeq ? { model: kept.model, fromSeq: first.messageSeq } : kept
}

现有实现（摘录）cost-pricing.ts · 汇总

export function priceSummary(snapshot: CostSnapshot, table: PriceTable, fallback: WindowFallback | null): CostSummary {
  const turns = new Map<number, { input: number; output: number; cost: number; priced: number; unpriced: number }>()
  const models = new Set<string>()
  let total = 0, savings = 0, pricedSteps = 0, unpricedSteps = 0
  for (const step of snapshot.steps) {
    // 记录只用于 fromSeq 之后的未归属步骤，其余 null 计入未定价
    const model = step.model ?? (fallback !== null && step.messageSeq >= fallback.fromSeq ? fallback.model : null)
    if (model !== null) models.add(model)
    const row = turns.get(step.turn) ?? { input: 0, output: 0, cost: 0, priced: 0, unpriced: 0 }
    row.input += step.miss + step.hit + step.write
    row.output += step.output
    const priced = priceStep(step, model, table)
    if (priced === null) { row.unpriced++; unpricedSteps++ }
    else { row.cost += priced.cost; row.priced++; total += priced.cost; savings += priced.savings; pricedSteps++ }
    turns.set(step.turn, row)
  }
  return {
    total, savings, models: [...models], pricedSteps, unpricedSteps,
    turns: [...turns].sort(([a], [b]) => a - b).map(([turn, r]) => ({
      turn, input: r.input, output: r.output,
      cost: r.priced === 0 ? null : r.cost,          // 整轮未定价
      partial: r.priced > 0 && r.unpriced > 0,       // 部分未定价，金额后加标记
      unpricedSteps: r.unpriced,                      // 标记的提示文案需要该轮未定价步数
    })),
  }
}

现有实现（摘录）src/config.ts · src/index.ts · 配置注入

export const CONFIG_GLOBAL = '__DSH_UI_COST_CONFIG__'

// min(0) 拒绝负数，max(Number.MAX_VALUE) 拒绝 Infinity
const price = z.number().min(0).max(Number.MAX_VALUE).required()
const unitPrices = z.object({ cacheHit: price, cacheMiss: price, output: price })
const modelPrices = z.object({ peak: unitPrices.required(), offPeak: unitPrices.required() })

// NaN 能通过所有范围检查，transform 回调又拿不到字段路径，因此整表检查并自行拼出路径
function rejectNaN(table: PriceTable): PriceTable {
  for (const [model, prices] of Object.entries(table))
    for (const period of ['peak', 'offPeak'] as const)
      for (const field of ['cacheHit', 'cacheMiss', 'output'] as const)
        if (Number.isNaN(prices[period][field]))
          throw new z.ValidationError('expected a finite number but got NaN', { path: ['prices', model, period, field] })
  return table
}

export const Config: z<Partial<Config>, Config> = z.object({
  // transform 只包住字典；包在整个对象外会使 default({}) 与 required 失效
  prices: z.transform(z.dict(modelPrices), rejectNaN).default({}),
})

// 宿主入口：不提供服务，只把校验后的配置写入页面
export function apply(ctx: Context, config: Config): void {
  ctx.on('webserver/index-inject', (table) => {
    table.push({ kind: 'global', name: CONFIG_GLOBAL, value: config })
  })
}

// 浏览器端：跨进程输入，用同一 schema 再校验一次；apply 第一行调用，早于任何注册
export function injectedPrices(injected: Partial<Config> | undefined): PriceTable {
  if (injected === undefined) {
    // 宿主入口成功时总会注入；拿不到说明宿主入口未运行或配置无效，不回退到内置价
    throw new Error(`client-ui-cost: the page carries no ${CONFIG_GLOBAL}; the Host entry is not loaded or its price configuration is invalid`)
  }
  return resolvePrices(Config(injected).prices)
}

const { useCost, useSession, useProjection, prices, loadOlder, windowModel, t } = props
const snapshot = useCost(value => value)
const lastUsed = useProjection('modelSelection', value => value?.lastUsed?.model ?? null)
const hasMore = useSession(session => session.hasMore)
const loadingOlder = useSession(session => session.loadingOlder)
// 部分失败时 loadOlder() 不抛错，而是把 historyLoadStatus 置为 'error'
const historyFailed = useSession(session => session.historyLoadStatus === 'error')
const [rejected, setRejected] = useState(false)
const summary = useMemo(() => {
  // 记录须与本次计价的快照同步；对相同输入幂等，重复渲染结果不变
  windowModel.current = rememberWindowModel(windowModel.current, snapshot, lastUsed)
  return priceSummary(snapshot, prices, windowModel.current)
}, [windowModel, snapshot, prices, lastUsed])
const requestOlder = (): void => {
  setRejected(false)
  loadOlder().catch((error: unknown) => {
    console.warn('client-ui-cost: loading earlier turns failed', error)
    setRejected(true)
  })
}
const older = !hasMore ? null : (
  <div className={css.older}>
    {/* 空状态下不显示“只统计已加载的 N 轮”，N 必须 ≥ 1 */}
    {snapshot.steps.length === 0 ? null : <span>{t('partial', { count: summary.turns.length })}</span>}
    {loadingOlder ? (
      <span role="status">{t('loadOlder.loading')}</span>
    ) : (
      <Button size="sm" variant="outline" onClick={requestOlder}>
        {rejected || historyFailed ? t('loadOlder.failed') : t('loadOlder')}
      </Button>
    )}
  </div>
)

export function formatYuan(value: number): string {
  if (value > 0 && value < 0.00005) return '<¥0.0001'
  // 4 位四舍五入会得到 1.0000 时改用 2 位
  return value >= 0.99995 ? `¥${value.toFixed(2)}` : `¥${value.toFixed(4)}`
}

summarize方案小结

本次新增一个独立的浏览器端实验插件，不改动现有事件、投影和服务：通过“每步取前一条请求头的模型”从已有日志中推出模型，计价规则集中在可单测的纯函数中。主要取舍是接受窗口最前段偶尔推不出模型（计入未定价，加载更早后恢复），以此避免修改核心事件格式和两套 SDK 快照；为缩小这一范围，series 请求头向前沿用其模型，视图按会话记住无请求头时的模型，窗口被整体替换时丢弃重记，实时更新时合计不会下降。压缩摘要调用和失败重试消耗的 token 不在本次统计范围内，估算可能偏低。实现中补充了 NaN 校验、宿主与浏览器两个编译面，以及空状态下仍可加载更早轮次；真实对话记录的模型 ID 与内置价目表一致，DeepSeek 当前报告的缓存写入量为 0。
